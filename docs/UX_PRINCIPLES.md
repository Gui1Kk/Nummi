# Princípios de UX

- cada tela possui uma ação principal clara;
- exclusões pedem confirmação;
- valores previstos não contaminam o saldo realizado;
- erros explicam a próxima ação;
- estados vazios ensinam o primeiro passo;
- formulários usam validação local e do servidor;
- mobile não depende de tabelas largas para funções essenciais.
