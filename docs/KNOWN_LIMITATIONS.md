# Limitações conhecidas

- SMTP, redirects, CAPTCHA e proteção contra senhas vazadas dependem do painel Supabase.
- O snapshot completo é limitado a 5.000 lançamentos por usuário; acima disso, use a API paginada.
- Transferências entre contas, parcelamentos e anexos permanecem fora do escopo atual.
- Alterar uma recorrência não reescreve ocorrências já realizadas.
