# Escopo dos testes de segurança

Coberto: isolamento RLS, propriedade de objetos, mass assignment, idempotência, limites de corpo/página/lote, CORS, JWT obrigatório, fórmula CSV, datas inválidas, referências cruzadas e exposição de erros. Não equivale a certificação absoluta; cada nova rota exige repetir a matriz.
